# Календарь звонков

Сервис, в котором гость бронирует время для звонка в календаре владельца.

## Язык предметной области

**Бронирование**:
Резервирование гостем интервала времени для звонка выбранного типа в календаре владельца.
_Избегать_: запись.

**Владелец календаря**:
Единственный человек, который определяет типы событий и просматривает бронирования в своём календаре.

**Гость**:
Человек, выбирающий тип события и бронирующий время для звонка без собственной учётной записи.

**Тип события**:
Вид звонка с уникальным идентификатором, названием, описанием и длительностью в минутах.
_Избегать_: вид брони.

**Слот**:
Доступный интервал времени в календаре владельца, подходящий для бронирования выбранного типа события.
